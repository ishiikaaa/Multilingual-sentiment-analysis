# Multilingual-sentiment-analysis
This project focuses on building a multilingual sentiment analysis model, with a primary focus on French web texts. It classifies text into positive, negative, or neutral sentiments using word-to-word translation and natural language processing techniques.

📌 Key Features
Handles multilingual web text (French-focused)

Word-to-word translation for normalization

Preprocessing: cleaning, tokenization, lemmatization

Sentiment labeling (positive/negative/neutral)

Supports ML and deep learning models (e.g., SVM, BERT)

⚙️ Tech Stack
Python, NLTK, spaCy, scikit-learn, Transformers
